How it works

Tenant isolation you don't have to remember

Add an entity, implement ITenantEntity, and you're done. ShipBlazor handles the rest on every query and every save.

  • Queries only return the current organization's rows
  • New rows get the right organization automatically
  • Writes to another organization's data are refused
  • No organization? Queries return nothing. It fails closed.
public class Invoice : ITenantEntity
{
    public Guid Id { get; set; }
    public Guid OrganizationId { get; set; } // set for you
    public decimal Amount { get; set; }
}

// In any page:
await using var db = await Tenant.CreateDbContextAsync();
var invoices = await db.Invoices.ToListAsync();
// → only this organization's invoices

db.Invoices.Add(new() { Amount = 99m });
await db.SaveChangesAsync();
// → OrganizationId stamped automatically

Questions

What exactly do I get?

The complete source code as a dotnet new template package plus a zip of the project, the documentation, the end-to-end tests, Docker files and the Azure templates. You install the template once and create new products with dotnet new shipblazor -n YourApp; every name in the code becomes yours.

Which versions does it use?

.NET 10 (long-term support), Blazor with server-side rendering, EF Core 10 and Bootstrap 5. Pages are server-rendered by default for speed and SEO; add interactivity to any page with one line.

Do I need Azure?

No. The Azure setup is there if you want one-command deployment, but the app is a standard Docker image that runs on any host, with PostgreSQL, SQL Server or SQLite.

Can I use it for client projects?

Yes. Build as many end products as you like, for yourself or for clients. You can't resell or publish ShipBlazor itself as a template or starter kit.

I'm new to Blazor. Is that OK?

If you know C# and ASP.NET Core you'll be at home. The code is deliberately simple, and the guides walk you through adding your first feature step by step.

How do updates work?

You get new versions for 12 months. Because the code becomes yours, updates come with a changelog listing what changed so you can bring in what you need.
